# Ollama and Qwen3-Coder

Install Ollama separately, pull `qwen3-coder:30b`, and leave its API bound to
loopback. Keeper accepts only `http://127.0.0.1`, `http://localhost`, or loopback
IPv6 endpoints and bounds responses to 4 MiB.

Qwen 2.5 remains disabled. Qwen3-Coder may author suitable work, but automated
verification and review by a different capable provider are mandatory. If no
independent reviewer is available, the run remains blocked.
