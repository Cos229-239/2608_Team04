# First Run

The Back/Next setup sequence explains authority boundaries, validates a unique
write probe inside the selected evidence directory, accepts an optional first
repository, shows provider diagnostics, and reports KeeperAuthority health.
Invalid or protected paths keep the user on the current step. Setup never starts,
stops, installs, or reconfigures KeeperAuthority.

After setup, describe the first project in Conversation. Keeper prepares a durable
charter proposal and selects that project in the header. Review every scope,
budget, provider, tool, workspace, privacy, and delegation field before choosing
Founder approval. Windows authentication is separate from the desktop review
dialog and can be canceled without creating a workflow.

The default evidence location can be changed through the application service and
is stored without credentials. A writable local data directory is mandatory.
Optional providers remain visibly unavailable until separately registered and
qualified.
